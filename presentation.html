Automate TPI Testing

Skill that runs a test plan item

  1. Creates a test plan with targeted variations
  2. Runs a dedicated subagent or subsession for each variation
  3. Launches every test in a separate, isolated VS Code instance observed through Playwright and the debugger
  4. Tracks progress, logs, workspace state, user data, chat session logs, timing, and screenshots
  5. Reports test results and discovered issues
  6. Recommends improvements to the test scripts and the skill itself
Reliable · isolated · observable
